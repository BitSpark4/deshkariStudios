```
PRIMARY (all buttons, links, icons):  #C45911  ← Deshkari Saffron

BORDER (all cards, dividers):         #e9e9e9  ← Light grey
FOOTER BG:                            #1a1a1a  ← Dark charcoal
```

## FONT — ONE FONT ONLY

```
font-family: 'Rubik', sans-serif;
Google Fonts URL: https://fonts.googleapis.com/css2?family=Rubik:wght@300;400;500;600;700

Weights used:
  300 — thin/light (rarely)
  400 — body text
  500 — nav links, labels
  600 — card titles, buttons, form labels
  700 — H1, H2, logo
```

## BUTTON — ONE STYLE

```
All CTAs = orange pill button
Background: #C45911
Color: white
Border-radius: 30px (full pill)
Padding: 14px 32px
Font: Rubik 600, 14px
Text: "Action →" (always with arrow)
Hover: bg → #a34a0e
```

## SECTIONS PATTERN (every page)

```
Every inner section:
  1. Small orange label  (12px, Rubik 600, uppercase, #C45911)
  2. H2 heading          (38px, Rubik 700, #262626)
  3. Content
  4. Optional CTA button

Alternating backgrounds:
  White    → Light (#f9f5f0) → White → Light...
  Exception: dark/orange sections (video, partners strip, blog preview)
```
